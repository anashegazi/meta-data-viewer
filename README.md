# 📊 Meta Data Viewer (عارض صفحات الإعلانات)

تطبيق ويب تفاعلي سريع ومستقل لعرض وفحص بيانات صفحات الفيسبوك المستخرجة من أداة **Meta Ads Library Collector**.

---

### ✨ المميزات:
- **سحب وإفلات (Drag & Drop):** اسحب أي ملف Excel (`.xlsx`) أو CSV تم استخراجه من الأداة وسيتم عرضه فوراً.
- **تصفية وبحث لحظي:** ابحث باسم الصفحة مباشرة مع عرض فوري للنتائج.
- **فلترة المنصات:** أزرار لاختيار المنصة (Facebook, Instagram, Messenger, Audience Network, Threads).
- **ترتيب مخصص:**
  - الأكثر / الأقل متابعين
  - الأحدث / الأقدم بدءاً
  - أبجدياً بالاسم
- **بطاقات مخصصة لكل صفحة:** شعار ملون لكل صفحة، عدد المتابعين، المنصات، تاريخ بدء الإعلان، وزر فتح مباشر في فيسبوك.
- **الوضع الليلي والنهاري (Dark / Light Mode):** دعم كامل للتبديل بين الوضعين.

---

### 🌐 الاستخدام عبر GitHub Pages:
يمكنك تفعيل **GitHub Pages** من إعدادات المستودع (Settings -> Pages -> Branch: `main` أو `master` -> Save) ليعمل الموقع كصفحة ويب مباشرة أونلاين.
